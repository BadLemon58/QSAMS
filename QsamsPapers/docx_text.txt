QSAMS: QR Code-Based Student Attendance Monitoring System for Notre Dame of Midsayap College
CHAPTER I: INTRODUCTION 
1.1 Background of the Project 
In the field of Information Technology, digital technologies simplify routine processes by automating repetitive tasks and storing information in a centralized system. Attendance of students is an essential element of class management since it enables teachers to monitor the participation of their students as well as collect accurate attendance records. One of the technologies that can be used for this purpose is the Quick Response (QR) code, which facilitates the efficient recording of attendance information through QR code scanning. This process can save class time and make attendance checking more convenient and manageable [1], [2].
The application of QR code technology for attendance monitoring has been adopted by various educational institutions around the world. Internationally, the University of Mataram in Indonesia developed an Android-based attendance system that uses QR code technology to record student attendance. The system allows students to scan QR codes while enabling lecturers to monitor attendance more efficiently and reduce proxy attendance through QR code and location verification [3]. In Philippines, General Emilio Aguinaldo National High School in Imus City, Cavite has developed the application of QR codes in classroom attendance [4], while Jesus F. Magsaysay Technical Vocational High School has researched on QR code identification cards for attendance monitoring [5]. It is evident from the above that QR technology is an effective substitute to traditional methods of attendance. At present, there is limited evidence of the implementation of QR code-based attendance monitoring systems among educational institutions in Midsayap. 
Currently, attendance can be taken by doing things like calling out names, having an attendance sheet, and manual data collection. Although these are simple ways to do so, they might waste time during lessons, especially with too many students. Also, manual collection of data can sometimes lead to errors or incomplete data. There might also be problems with attendance forgery, as students who are not in class might have another one report their attendance for them. To address these issues, a better method needs to be developed [6], [2].
To address these challenges, the researchers propose the development of the QR Code-Based Student Attendance Monitoring System (QSAMS), which combines QR code generation, scanning, attendance recording, and monitoring in one platform. The system automatically refreshes QR codes at set intervals to help prevent unauthorized attendance recording [7], [8]. It is designed to make attendance checking faster, more secure, and more convenient for both teachers and students [9]. Teachers can easily create class lists using a QR code or class code, while attendance can be recorded by scanning a student's personal QR code or a QR code generated for the class. To make sure only students who are actually in the classroom can check in, the system only accepts scans from devices within the allowed range. The proposed system will be developed for Notre Dame of Midsayap College (NDMC), with teachers and students as its primary users.
QSAMS will be developed as a Progressive Web Application (PWA) using React for the front-end, Vite as the build tool, Tailwind CSS for the user interface, and Supabase with PostgreSQL for secure data storage and management. This technology stack will support efficient QR code generation, attendance recording, user authentication, and attendance monitoring for both teachers and students. The system will be deployed for use at Notre Dame of Midsayap College (NDMC) to provide a secure, accessible, and efficient solution for managing student attendance.
1.3 Objectives of the Project
The primary objective of this project is to develop a QR code-based attendance management system that makes attendance checking more organized, more secure, faster, and easier for teachers while allowing students to conveniently monitor their own attendance records.
Specifically the system will allow the following:
Teachers:
Add, Edit, Delete list of students.
Update the profile picture and change the password.
Scan and Generate QR code 
Record and Edit the Students attendance
Monitor and review students’ attendance record.
Generate Attendance record.
Students: 
Update the profile picture and change the password.
Scan and Generate QR code 
View attendance record
Enter classroom through QR Code and Code.
1.4 Significance of the Project
The project will be advantageous for the following recipients:
Teachers. Through this project, teachers will be able to save time in managing the attendance in class. They will be able to manage this without having to manually record the details, but by using a computerized method that organizes their attendance data. This will give them more time to teach in class. 
Students. Students will have convenient access to their attendance records, allowing them to monitor their attendance status, view their attendance history, and keep track of their class participation. This will encourage students to become more responsible and accountable for maintaining regular attendance.
Notre Dame of Midsayap College (NDMC). The institution will benefit from a more reliable and efficient attendance monitoring process. By replacing manual attendance with a digital system, the college can improve record management, reduce paperwork, and support its goal of integrating modern technology into academic operations.
1.5 Scope and Delimitations of the Project
The study focuses on the development of the QR Code-Based Student Attendance Monitoring System (QSAMS) for Notre Dame of Midsayap College (NDMC). The system will be developed as a Progressive Web Application (PWA) that can be accessed through a web browser or installed on compatible mobile devices for added convenience. It is designed for authorized teachers and enrolled students of the institution, providing a more efficient and secure alternative to the traditional attendance process. By integrating QR code technology, user authentication, and a secure cloud database into a single platform, QSAMS aims to simplify attendance management while ensuring the accuracy and reliability of attendance records.
The system will provide teachers with tools to efficiently manage attendance and class records. Teachers will be able to create class lists using both QR code and unique class code, allowing students to join their assigned classes quickly and conveniently. During each class session, teachers may either scan a student's personal QR code or generate a QR code for students to scan when recording their attendance. To enhance attendance security, the generated QR code will automatically refresh after a specified period, and the system will only accept attendance scans from devices within the designated range to help ensure that only students who are physically present can check in. In addition, teachers will be able to review attendance records, monitor student attendance, and generate attendance reports whenever needed.
Students will be able to join classes using the class code provided by their teacher and record their attendance through QR code scanning. The system will also allow them to view their attendance history, attendance rate, total sessions attended, and recorded absences, enabling them to keep track of their attendance throughout the semester. All attendance records will be securely stored in the system's cloud database, providing both teachers and students with convenient access to accurate and up-to-date attendance information.
However, this study has several limitations. The proposed system is intended only for authorized teachers and enrolled students of Notre Dame of Midsayap College (NDMC). It is designed specifically for attendance monitoring and does not cover other academic functions such as enrollment, grading, class scheduling, or student information management. Since QSAMS is a web-based system, a stable internet connection is required to access its features and keep attendance records up to date. In addition, QR code scanning requires a compatible device with a working camera. The system is also limited to its own attendance management functions and does not support integration with other institutional systems or third-party educational platforms.
1.6 Definition of Terms
The following terms are defined conceptually and operationally to clarify the key terms used in the QR Code-Based Student Attendance Monitoring System (QSAMS).
Attendance History. Refers to the record of a student's attendance, including the dates and status of attendance for each class session. In QSAMS, it allows students and teachers to review previous attendance records.
Attendance Monitoring. Refers to the process of recording, tracking, and managing student attendance. In QSAMS, attendance monitoring is performed through QR code scanning and stored digitally for easy access and reporting.
Attendance Rate. Refers to the percentage of classes attended by a student based on the total number of class sessions. In QSAMS, this information is automatically calculated and displayed for students and teachers.
Authorized Teacher. Refers to a registered faculty member who has permission to access QSAMS. Teachers can create classes, manage student attendance, generate QR codes, view attendance records, and generate attendance reports.
Class Code. Refers to a unique code generated for each class that allows students to join their assigned class. In QSAMS, students can join a class by entering the class code or by scanning the corresponding class join QR code.
Class Join QR Code. Refers to the QR code generated for a specific class that allows enrolled students to quickly join the class by scanning it. In QSAMS, students may join a class either by scanning the class join QR code or by entering the corresponding class code.
Cloud Database. Refers to the online database used to securely store and manage user information, class data, and attendance records. QSAMS uses a cloud database to ensure that attendance information is updated and accessible whenever an internet connection is available.
Enrolled Student. Refers to a student officially registered in a class who is authorized to access QSAMS. Students can join classes, record their attendance, and view their attendance records through the system.
Notre Dame of Midsayap College (NDMC). Refers to the educational institution in Midsayap, Cotabato, where the proposed QR Code-Based Student Attendance Monitoring System (QSAMS) will be developed and evaluated.
PostgreSQL. Refers to the relational database management system used by QSAMS to store and organize user information, class data, and attendance records securely.
Progressive Web Application (PWA). Refers to a web application that can be accessed through a web browser or installed on compatible mobile devices. In QSAMS, the PWA allows teachers and students to use the system conveniently without requiring a traditional mobile application.
QR Code (Quick Response Code). Refers to a two-dimensional barcode capable of storing digital information that can be scanned using a compatible device. In QSAMS, QR codes are used to record student attendance quickly and accurately.
QR Code-Based Student Attendance Monitoring System (QSAMS). Refers to the proposed attendance management system developed for Notre Dame of Midsayap College. The system uses QR code technology to record, monitor, and manage student attendance while providing teachers and students with a faster, more organized, and secure attendance process.
React. Refers to the JavaScript library used to develop the user interface of QSAMS. It provides a responsive and interactive environment for teachers and students when using the system.
Supabase. Refers to the cloud-based backend platform used by QSAMS for user authentication, database management, and secure storage of attendance records.
Tailwind CSS. Refers to the utility-first CSS framework used to design the user interface of QSAMS, providing a responsive, consistent, and user-friendly appearance across different devices.
User Authentication. Refers to the process of verifying the identity of teachers and students before allowing access to the system. In QSAMS, user authentication helps ensure that only authorized users can access attendance records and system features.
Users. Refers to all registered individuals who interact with QSAMS, specifically authorized teachers and enrolled students. Each user is provided with appropriate access based on their assigned role.
Vite. Refers to the build tool used in developing QSAMS. It provides a fast development environment and improves the performance of the web application during development and deployment.
